# Ninja Strike

瀏覽器 3D 第一人稱射擊遊戲原型。玩家在軍事基地中使用手槍對抗機器人敵人。

## How to Play

1. 在專案資料夾啟動本機伺服器：

   ```text
   python -m http.server 8000
   ```

2. 開啟 `http://localhost:8000/`。
3. 點擊「開始任務」，允許滑鼠鎖定。

## Controls

- `WASD`：移動
- 滑鼠：轉動第一人稱視角
- 滑鼠左鍵：射擊
- `R`：重新裝填
- `Esc`：暫停或解除滑鼠鎖定

## Features

- Three.js 3D 軍事基地
- 第一人稱移動與滑鼠視角
- 手槍彈藥與重新裝填
- 機器人敵人追擊
- 場景障礙碰撞
- 機器人遠程攻擊
- 生命值、擊中提示、勝利與失敗畫面
- 暫停與繼續任務

## Notes

目前使用 CDN 載入 Three.js，無需安裝 npm 套件。這是最小可玩原型，下一階段可再加入正式模型、音效、更多武器與關卡。
